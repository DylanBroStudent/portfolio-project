Project Rangi

Starting as an experiment in making shaders, I built a shader in godot that changed its colour based on the normal value of the geometry, so that a platformer game could have a visual representation of what surfaces are able to be stood on.

It quickly turned into a whole project involving building a 3rd person player controller, modelling and rigging a player character, and creating menu systems.
